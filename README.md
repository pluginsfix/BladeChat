# BladeChat

Современный, производительный и надежный плагин управления чатом для серверов Minecraft (Paper / Purpur / Spigot 1.16.5 - 1.21.4) на Java 21 LTS. Разработан специально для проекта **BladeStudio**.

## Особенности

- Полная поддержка Paper, Purpur и Spigot (1.16.5 - 1.21.4).
- Работа на современной Java 21 LTS.
- Локальный и глобальный чат с настраиваемым радиусом (Ranged Mode).
- Встроенная система обнаружения и предотвращения рекламы (IP, домены, настраиваемый белый список).
- Безопасная интеграция с Vault и PlaceholderAPI (без крашей и задержек).
- Гибкая настройка форматирования чата с поддержкой префиксов, суффиксов и плейсхолдеров.
- Кастомизируемые сообщения входа, выхода и исключения игроков.
- Разграничение прав на цвета, жирный шрифт, магический текст и другие стили.
- Чистый, производительный код без устаревших библиотек и метрик.

## Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/bladechat help` | Список доступных команд | `bladechat.admin` |
| `/bladechat reload` | Перезагрузка конфига и сообщений | `bladechat.reload` |
| `/bladechat clear` | Очистка игрового чата | `bladechat.clear` |

### Права форматирования чата:
- `bladechat.chat.color` — доступ к цветам (`&a`, `&b` и т.д.)
- `bladechat.chat.bold` — доступ к жирному тексту (`&l`)
- `bladechat.chat.magic` — доступ к магии (`&k`)
- `bladechat.chat.strikethrough` — доступ к зачеркиванию (`&m`)
- `bladechat.chat.underline` — доступ к подчеркиванию (`&n`)
- `bladechat.chat.italic` — доступ к курсиву (`&o`)
- `bladechat.chat.reset` — доступ к сбросу цвета (`&r`)
- `bladechat.bypassads` — обход фильтра рекламы
- `bladechat.notifyad` — уведомления о попытках отправки рекламы

## Сборка проекта

```bash
mvn clean package
```

Скомпилированный `.jar` файл будет находиться в директории `target/`.
